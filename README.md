## How to Find More Winners

- **Devpost:** `https://<event>.devpost.com/project-gallery`, then filter by **Winners**. The `/updates` tab usually has the official announcement.
- **lablab.ai:** `https://lablab.ai/ai-hackathons/<event>/live` lists winners and runners-up, and `lablab.ai/ai-articles` has the write-ups.
- **Devfolio:** open the event microsite, then the **Projects** tab, and filter by prize ([guide](https://guide.devfolio.co/docs/guide/Projects/view-submissions)).
- **ETHGlobal:** `https://ethglobal.com/showcase` and filter by event and prize.
- **Kaggle:** `https://www.kaggle.com/competitions/<competition>/writeups`.
- **AI Tinkerers:** `https://<city>.aitinkerers.org/hackathons/<id>/results`.
