## How to Find More Winners

| Platform | Pattern |
|---|---|
| Devpost | `https://<event>.devpost.com/project-gallery`, then filter by **Winners**. The `/updates` tab usually has the announcement. |
| Devfolio | `https://<event>.devfolio.co/projects`, then filter by prize ([guide](https://guide.devfolio.co/docs/guide/Projects/view-submissions)) |
| ETHGlobal | `https://ethglobal.com/events/<event>/prizes` for finalists; `https://ethglobal.com/showcase` for all projects |
| lablab.ai | `https://lablab.ai/ai-hackathons/<event>/live` |
| Kaggle | `https://www.kaggle.com/competitions/<competition>/writeups` |
| AI Tinkerers | `https://<city>.aitinkerers.org/hackathons/<id>/results` |
| DEV Community | Winner posts are under [`dev.to/devteam`](https://dev.to/devteam) and tagged `#devchallenge` |
| Hashnode | Winner posts are on [`townhall.hashnode.com`](https://townhall.hashnode.com) |
